## API TORIUM ĐÃ REVERSE ENGINEER — ĐÂY LÀ DỮ LIỆU THẬT, DÙNG CHÍNH XÁC

### Base URL

https://api.torium.network


### Authentication
Tất cả request (trừ /device/session) PHẢI có header:

Authorization: Bearer {token}
x-app-version: 2.1.0
x-device-id: {deviceId}
x-ota-version: 0a9f87c3-0a5f-4ed5-aefd-7a9004875813
User-Agent: okhttp/4.12.0
Content-Type: application/json
Accept-Encoding: gzip


### Endpoint 1 — Đăng ký Device Session

POST https://api.torium.network/device/session

Request Body:
{
"platform": "android",
"deviceId": "{deviceId}",
"deviceModel": "V2452A",
"osVersion": "16",
"appVersion": "2.1.0",
"isRooted": false,
"clerkId": "{clerkId}"
}

Response: {"success": true}


### Endpoint 2 — Check Mining Status

GET https://api.torium.network/v1/mining/v2/session-status
Headers: Authorization required

Response:
{
"status": "mining",
"rate": 0.48
}


### Endpoint 3 — Check Wallet Balance

GET https://api.torium.network/v1/wallet/balance
Headers: Authorization required


### Endpoint 4 — Check Boost State

GET https://api.torium.network/v1/mining/boost-state?abVariant=unlimited
Headers: Authorization required


### Endpoint 5 — Tạo Rewarded Intent (BƯỚC 1 XEM AD)

POST https://api.torium.network/v1/mining/v2/rewarded-intents
Headers: Authorization required

Response 201:
{
"intentId": "rad_{uuid}"
}


### Endpoint 6 — Verify Rewarded Intent (BƯỚC 2 XEM AD)

GET https://api.torium.network/v1/mining/v2/rewarded-intents/{intentId}
Headers: Authorization required

Response 200:
{
"status": "verified",
"verifiedAt": {timestamp_ms},
"expiresAt": {timestamp_ms},
"failureReason": null,
"consumedAt": null
}


### Endpoint 7 — Boost Mining (BƯỚC 3 XEM AD — QUAN TRỌNG NHẤT)

POST https://api.torium.network/v1/mining/v2/boost
Headers: Authorization required

Request Body:
{
"verifiedIntentId": "{intentId_từ_bước_1}",
"adRevenue": {
"currency": "USD",
"precision": 3,
"valueMicros": 10092,
"occurredAt": {current_timestamp_milliseconds},
"localDateKey": "{YYYY-MM-DD}",
"utcOffsetMinutes": 420
}
}

Response 200:
{
"boostCount": 3,
"totalBoostRate": 0.24,
"newRate": 0.704,
"grantedSlots": 1,
"bucket": {
"hourlyRemaining": 2,
"hourlyResetAt": {timestamp_ms},
"dailyRemaining": 117,
"dailyCap": 120,
"hourlyCap": 5,
"cooldownEndsAt": {timestamp_ms},
"cooldownRemainingMs": 10000
}
}


### Endpoint 8 — Activity Ticker (Keepalive)

GET https://api.torium.network/v1/activity/ticker
Headers: Authorization required


### RATE LIMITS — BẮT BUỘC TUÂN THỦ
- Tối đa 5 lần boost per giờ (hourlyCap: 5)
- Tối đa 120 lần boost per ngày (dailyCap: 120)
- Cooldown 10 giây giữa mỗi lần boost (cooldownRemainingMs: 10000)
- Sau mỗi boost PHẢI đọc response để biết hourlyRemaining còn bao nhiêu
- Nếu hourlyRemaining = 0, PHẢI chờ đến hourlyResetAt mới boost tiếp

### FLOW XEM AD HOÀN CHỈNH (3 bước tuần tự, KHÔNG ĐƯỢC bỏ bước nào)

Bước 1: POST /v1/mining/v2/rewarded-intents → lấy intentId
Bước 2: GET /v1/mining/v2/rewarded-intents/{intentId} → verify (status phải là "verified")
Bước 3: POST /v1/mining/v2/boost với intentId đó → claim boost
Bước 4: Đọc cooldownRemainingMs từ response → sleep đúng số ms đó trước lần tiếp theo

## ĐĂNG KÝ TÀI KHOẢN TỰ ĐỘNG

### Flow đăng ký
Torium dùng Clerk auth system. Login screen: Email + Password.
Register screen: Email + Password + Referral Code (optional) + Cloudflare Turnstile captcha.

**Quan trọng:** Cloudflare Turnstile được USER tự solve thủ công. Tool KHÔNG tự bypass captcha.

### Đọc email OTP qua dongvanfb.net API
Torium gửi OTP verify email sau khi đăng ký.
Tool tích hợp API đọc hộp thư Hotmail qua dongvanfb.net.

**Format account import:**

email|password|refresh_token|client_id

(mỗi dòng 1 account, dùng ký tự pipe | làm delimiter)

**API đọc email dongvanfb.net:**
- Endpoint: https://docs.dongvanfb.net/ (đọc docs để lấy endpoint chính xác)
- Method: OAuth2
- Input: email|password|refresh_token|client_id
- Output: đọc hộp thư, lấy OTP từ email Torium

**Flow đăng ký tự động:**
User import file accounts.txt (format email|password|refresh_token|client_id)
Tool mở Torium register trong container tương ứng
Tool tự điền email + password vào form
Tool hiển thị popup "Vui lòng solve captcha Cloudflare" → user tự solve
User nhấn "Đã solve xong" trong ToriumBot
Tool gọi dongvanfb.net API để đọc email OTP
Tool tự điền OTP vào app Torium
Tool extract Bearer token từ container sau khi login thành công
Lưu toàn bộ thông tin account vào SQLite

## SCHEDULER LOGIC — BẮT BUỘC ĐÚNG

### Ad watching scheduler (per account)
Mỗi account có interval_hours riêng (user set, default 2 giờ)
Khi đến giờ: thực hiện flow xem ad
Sau khi xem xong: đọc bucket từ response
Nếu hourlyRemaining > 0 VÀ cooldownRemainingMs đã hết: có thể xem thêm trong giờ này
Nếu hourlyRemaining = 0: schedule lần tiếp theo = hourlyResetAt
Nếu dailyRemaining = 0: dừng hôm nay, schedule lần tiếp = 00:01 ngày mai theo UTC+7
Giữa các lần xem trong cùng 1 giờ: sleep cooldownRemainingMs milliseconds
KHÔNG bao giờ vượt quá hourlyCap (5) hoặc dailyCap (120)

### Daily check-in scheduler (per account)
Check-in ĐÚNG 24 giờ sau lần check-in trước
Giờ check-in random trong khung ±30 phút so với giờ check-in lần đầu
Ví dụ: check-in đầu lúc 08:00 → lần sau random từ 07:30-08:30
Múi giờ UTC+7

### Proxy switch logic (per container)
Trước khi thực hiện BẤT KỲ action nào cho 1 container:
Kết nối proxy của account đó
Verify proxy hoạt động bằng cách ping https://api.torium.network
Nếu proxy chết → alert Telegram ngay → skip account này → qua account tiếp theo
Chỉ khi proxy verify OK → mới thực hiện action

## RETRY LOGIC — BẮT BUỘC

Với MỌI API call đến api.torium.network:

Attempt 1 → nếu thất bại → log WARNING → chờ 5 giây
Attempt 2 → nếu thất bại → log WARNING → chờ 10 giây
Attempt 3 → nếu thất bại → log ERROR → alert Telegram → mark account là ERROR → skip
Nếu response là 401 Unauthorized → token hết hạn → alert Telegram "Token cần refresh cho account {email}"
Nếu response là 403 Forbidden → account có thể bị ban → alert Telegram "Account {email} có thể đã bị ban"

## CRANE CONTAINER MANAGEMENT

Crane là tweak jailbreak cho phép clone app thành nhiều container độc lập.
Mỗi container có:
- Bundle ID riêng (vd: network.torium.app.clone1, .clone2, ...)
- Storage riêng hoàn toàn (UserDefaults, Keychain, Documents)
- Network traffic riêng

ToriumBot tương tác với Crane qua:
Đọc danh sách containers qua Crane API/filesystem
Mở container cụ thể bằng URL scheme hoặc openURL
UIAutomation để điều khiển app trong container
Network interception để lấy Bearer token

## PROXY CONFIGURATION

Hỗ trợ: HTTP, HTTPS, SOCKS4, SOCKS5

Mỗi account lưu:

proxy_protocol: http | https | socks4 | socks5
proxy_host: string
proxy_port: integer
proxy_username: string (optional)
proxy_password: string (optional)


Proxy được set per-request trong URLSession configuration của account đó:
```swift
// Pseudo-code
let config = URLSessionConfiguration.default
config.connectionProxyDictionary = [
  kCFNetworkProxiesHTTPEnable: true,
  kCFNetworkProxiesHTTPProxy: proxyHost,
  kCFNetworkProxiesHTTPPort: proxyPort
  // tương tự cho SOCKS
]
let session = URLSession(configuration: config)
```

Verify proxy trước khi dùng:

GET https://api.torium.network/v1/mining/v2/session-status qua proxy đó
Timeout: 10 giây
Nếu thành công → proxy OK
Nếu timeout/error → proxy chết → alert
